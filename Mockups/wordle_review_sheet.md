# Wordle category levels - review sheet

Every Wordle level word: 3 languages x 7 categories x 6 levels (words grow from 4 to 7 letters). The game shows the Clue and, after the game, the meaning.
The words were picked automatically from the dictionary files (clean single-meaning entries first, one meaning per level). Please check each row with a native speaker: spelling, dialect, loanwords (for example the Spanish-style numbers) and whether the clue is clear.
To fix a word, edit Assets/Main/Resources/Wordle/wordle_levels.json (letters A-Z only, keep each category's levels from shortest to longest).
