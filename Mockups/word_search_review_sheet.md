# Word Search review sheet

Every word in the Word Search puzzles, with what the game shows as its English meaning and what the dictionary file says about the word.
Rows marked **CHECK** have a dictionary entry with more than one meaning (or a verb sense), so the automatic pick may be the wrong meaning. Please check all rows with a native speaker.
To fix a word, edit Assets/Main/Resources/WordSearch/wordsearch_puzzles.json (keep each puzzle at 7-8 words, 3-8 letters per word).
Note: the same spelling can mean different things in different languages (for example LANGGAM is a bird in Cebuano but an ant in Tagalog).
